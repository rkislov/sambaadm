Подключение helper

Подготовьте узел, зарегистрируйте его и установите комплект подключения.

{{if .Content}}
Существующий ключ: подготовка CSR на узле

1 Подготовьте управляемый узел

Выполните от root на сервере, где установлен helper. Закрытый ключ останется на этом узле.

install -d -m 0700 /etc/sambaadm-helper
cd /etc/sambaadm-helper
umask 077
if [ ! -f tls.key ]; then
  openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:P-256 -out tls.key
fi
openssl req -new -key tls.key -out helper.csr -subj /CN=helper
cat helper.csr

1 Зарегистрируйте узел

Вставьте весь вывод helper.csr, включая строки BEGIN и END.
Параметры узла

Комплект содержит конфигурацию, сертификат и открытый ключ доверия.

2 Установите комплект

Распакуйте ZIP во временный каталог на управляемом узле и установите файлы:

install -o root -g root -m 0600 config.yaml tls.crt management.pub /etc/sambaadm-helper/
# Если ZIP содержит новый закрытый ключ:
if [ -f tls.key ]; then
  install -o root -g root -m 0600 tls.key /etc/sambaadm-helper/
fi
systemctl enable --now sambaadm-helper

Для SYSVOL создайте /etc/sambaadm-helper/domain.password с паролем служебной записи и правами 0600. Затем перезапустите sambaadm на управляющем сервере.

Повторная регистрация того же DNS-имени выпускает новый сертификат. Обновите файлы на узле и перезапустите helper.
