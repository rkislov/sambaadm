# Плагин Caja: предыдущие версии файлов SMB

[Скачать RPM 0.1.1](https://github.com/rkislov/sambaadm/releases/download/caja-v0.1.1/caja-smb-previous-versions-0.1.1-alt1.noarch.rpm) · [Выпуск, исходники и SHA256SUMS](https://github.com/rkislov/sambaadm/releases/tag/caja-v0.1.1)

Расширение добавляет пункт **«Предыдущие версии…»** в контекстное меню сетевого файла или папки в Caja. Можно открыть снимок или сохранить копию рядом с исходным файлом. Существующий файл не перезаписывается.

## Установка на рабочей станции ALT Linux

Пакет предназначен для Caja (MATE) на клиентском компьютере. Установка на DC, сервер sambaadm или установка helper для этого не нужны. RPM `noarch` подходит для x86_64 и aarch64.

1. Скачайте RPM и `SHA256SUMS` из выпуска. Проверьте контрольную сумму нужного RPM:

   ```sh
   sha256sum --ignore-missing -c SHA256SUMS
   ```

2. Установите пакет с зависимостями:

   ```sh
   sudo apt-get update
   sudo apt-get install ./caja-smb-previous-versions-0.1.1-alt1.noarch.rpm
   ```

3. Перезапустите Caja от имени пользователя, либо выйдите из сеанса и войдите снова:

   ```sh
   caja -q
   ```

4. Проверьте билет доменной учётной записи командой `klist`. При необходимости получите его через `kinit login@ВАШ.ДОМЕН`. Откройте `smb://сервер/ресурс` в Caja и выберите **«Предыдущие версии…»** в контекстном меню файла или папки.

Пароли в URL не используются. Расширение запрашивает снимки через `smbclient` с текущим Kerberos-билетом, а открывает и копирует файлы через GVfs.

## Что требуется на файловом сервере

На Windows должны быть включены теневые копии тома. На Samba нужны готовые снимки ZFS/LVM и их публикация через `shadow_copy2`. Расширение использует общий протокол SMB Previous Versions; выбирать Windows/ZFS/LVM вручную не нужно. Создание и расписание снимков на сервере настраиваются отдельно.

Отсутствие версий может означать отсутствие снимков, файла в снимке или прав доступа. Расширение показывает отдельную ошибку, когда сервер явно сообщает об отсутствии поддержки.
