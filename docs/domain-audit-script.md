# Автоматическая проверка домена на ALT p10

`scripts/samba-domain-audit.py` запускается **локально на каждом DC** из root-оболочки. Нужны Python 3 и штатные команды установленной Samba; дополнительных Python-пакетов нет. Пароль домена не запрашивается: локальные команды используют права root и машинную запись (`-P`). Скрипт не исправляет AD, ACL, DNS и службы, не запускает репликацию/KCC и не делает резервную копию.

## Запуск

Скопируйте один файл на контроллер. Войдите как root через `su -` и выполните:

```sh
python3 /path/to/samba-domain-audit.py
```

В начале выводится `OUTPUT=/var/tmp/samba-domain-audit-...`. Повторите запуск на остальных RWDC и RODC. Каждый запуск создаёт новый закрытый каталог. Чтобы указать свой **новый** каталог:

```sh
python3 /path/to/samba-domain-audit.py --output /var/tmp/audit-dc-20261120
```

Домен, DC, private dir, sam.ldb и SYSVOL определяются через `testparm` из локального `smb.conf`. Нет привязки к имени домена, IP, количеству DC и площадкам. Состав Configuration читается через `--cross-ncs`, без предположения, что домен совпадает с корнем леса. При нестандартной конфигурации:

```sh
python3 /path/to/samba-domain-audit.py \
  --smb-conf /custom/samba/smb.conf \
  --domain corp.example --dc dc1.corp.example \
  --dns-server 192.0.2.10 --site Branch-01
```

Замените значения своими. `--domain` и `--dc` задают имена для DNS-проверок; они не переключают локальную базу на другой DC. Чтобы проверить другой контроллер, запускайте файл на нём.

## Результаты

- `report.html` — отчёт, открываемый в браузере без сети; ссылки ведут на исходный вывод.
- `report.json` — машинный отчёт с командами, временем, кодом возврата, статусом и ограничениями.
- `summary.txt` — краткая сводка.
- `raw/` — ограниченный вывод каждой команды, включая ошибки.
- `sysvol-manifest.json` — пути, размеры и SHA-256 файлов SYSVOL, **без содержимого файлов**.
- `SHA256SUMS` — контрольные суммы материалов; проверка: `sha256sum -c SHA256SUMS` внутри каталога.

Передавайте весь каталог, сохраняя структуру. Например, упакуйте его через `tar -czf audit.tar.gz -C /var/tmp ИМЯ_КАТАЛОГА`. Не публикуйте материалы: в них есть внутренние имена, DN, адреса и диагностические журналы. Каталог создаётся с правами 0700, файлы — 0600. Пароли, закрытые ключи и полная база AD намеренно не собираются; состав выводимых системных журналов всё равно проверьте перед передачей.

JSON этого скрипта — самостоятельный формат `samba-domain-audit-v1`. Его нельзя загружать в sambaadm как снимок `sambaadm-helper collect`. Для такого импорта отдельно используйте штатный helper.

На RODC запрос `drs showrepl -P` может вернуть `8453 WERR_DS_DRA_ACCESS_DENIED`. Это неполученные данные, а не доказанная поломка репликации. Проверьте тот же RODC через «Состояние репликации» в sambaadm с доменными правами либо повторите команду вручную с `-U АДМИНИСТРАТОР` вместо `-P`, вводя пароль в запрос. Не добавляйте пароль в скрипт. `rpm -q` возвращает код 1, если отсутствует хотя бы один перечисленный пакет: смотрите строки по каждому пакету отдельно.

## Как понимать статус и код завершения

`ok` относится только к конкретной проверке. `observed` означает полученные данные, требующие разбора; `warning`/`error` — замечания; `unknown` — проверка недостоверна или недоступна; `skipped` — пропущена. Зелёный DRS не отменяет ошибок dbcheck и не доказывает совпадение SYSVOL. Хеши файлов не сравнивают ACL и не подтверждают применение GPO пользователем.

- **0** — обязательные проверки завершены, классифицированных замечаний нет; это не аттестация всей инфраструктуры.
- **1** — найдены ошибки/предупреждения; одновременно возможен неполный сбор, смотрите `collectionComplete`.
- **2** — неверные параметры, ошибка подготовки или прерывание.
- **3** — сбор неполный, классифицированных замечаний нет.

Отсутствующий инструмент, таймаут и превышение лимита никогда не превращаются в `ok`. Пустой список партнёров DRS считается неподтверждённым состоянием, включая одиночный DC. Свежесть репликации оценивается по времени успеха и расписанию площадок; единого порога в скрипте нет.

## Нагрузка и ограничения

По умолчанию команда ограничена 120 секундами и 8 МиБ вывода. dbcheck читает локальную базу и может нагрузить большой домен. SYSVOL ограничен 20 000 файлов и 256 МиБ чтения; символические ссылки не обходятся, меняющиеся/недоступные файлы отмечаются как неполный сбор. Запускайте в согласованное время, приостановив редактирование GPO для последующего сравнения хешей.

```sh
# Увеличить время для большой базы
python3 /path/to/samba-domain-audit.py --timeout 600

# Быстрый частичный сбор, без dbcheck и хеширования файлов
python3 /path/to/samba-domain-audit.py --skip-dbcheck --skip-sysvol-manifest

python3 /path/to/samba-domain-audit.py --help
```

Без root запуск отклоняется. `--allow-unprivileged` разрешает ограниченный сбор, но привилегированные проверки остаются неподтверждёнными. Скрипт не устанавливает недостающие программы и не меняет права. Он не проверяет резервное восстановление, интерактивный/автономный вход, клиентское применение политик, полноту прав и Authentication-аудита. Эти проверки дополняют отчёт отдельно.
