# Документация sambaadm

Комплект для версии 0.56.0 от 27 ноября 2026 года. Начните с инструкции по вашему сценарию. Руководства и иллюстрации используют учебные имена и адреса; заменяйте их данными своей организации.

- **Новый лес или ещё один контроллер:** [развёртывание домена с нуля, RWDC и RODC](domain-init.md), [Word со скриншотами](domain-init-guide/sambaadm-domain-init-guide.docx). Подготовка ALT Linux, проверка репозиториев, мастер, helper, сайты, сертификаты и журнал.
- **Первый Samba RWDC в Windows AD:** [мастер, ограничения и порядок вывода Windows DC](windows-migration.md). Режим предварительной проверки; настоящий Windows DC ещё не проверен.
- **Сетевые папки через GPO:** [подключение SMB-ресурса на ALT Linux p10 со скриншотами](gpo-drive-maps.md).
- **Повторная доставка GPO с Windows DC:** [управляемая синхронизация SYSVOL](sysvol-sync.md). Kerberos, предпросмотр, версии, владельцы/группы/DACL, конфликты и журнал.
- **Снятие роли RWDC/RODC:** [переход в обычный сервер — член домена](domain-demote.md). Подготовка, предпросмотр, сохранение данных и продолжение после сбоя.
- **Установка панели:** [короткая инструкция](quick-install.md), [полная установка, SSO, обновление и откат на ALT](alt-install.md). `sambaadm-setup` подключает панель к существующему домену; `samba-domain-init` создаёт новый лес.
- **Администратор:** [руководство онлайн](admin.md), [Word с иллюстрациями](admin-guide/sambaadm-admin-guide.docx). Полный цикл домена, ежедневные операции, службы, аудит, восстановление и вывод из эксплуатации.
- **Оператор и сотрудник:** [руководство онлайн](user.md), [Word с иллюстрациями](user-guide/sambaadm-user-guide.docx). Смена оператора, личный кабинет, каталог, службы, helpdesk и передача инцидентов.
- **Файловый HA-кластер:** [веб-интерфейс со скриншотами](filecluster-ui/README.md), [ZFS, iSCSI multipath и результаты проверок p10/p11](filecluster-zfs.md).
- **Подключение серверов:** [helper, установка по SSH, TLS и регистрация](helper.md).
- **DHCP Kea:** [установка, оснастка RSAT, relay и HA на АЛЬТ p10/p11](dhcp-kea.md).
- **Печать:** [CUPS, журнал заданий, IPP/Kerberos и драйверы Windows](printing.md).
- **DNS:** [делегирование поддоменов, условная пересылка, доставка и переключение DNS-бэкенда](dns-routing.md).
- **Аудит:** [действия пользователей, JSON и настройка CEF в syslog](audit-cef.md).
- **Восстановление:** [восстановление домена и ограничения](domain-recovery.md).
- **Рабочие станции с Caja:** [плагин предыдущих версий файлов SMB](caja-plugin.md).

[Скачать комплект релиза](https://github.com/rkislov/sambaadm/releases/tag/v0.56.0). Перед установкой проверьте доступность репозиториев и пакетов, затем сверяйте файлы релиза с `SHA256SUMS`.
