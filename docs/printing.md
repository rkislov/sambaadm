# Серверы печати

Раздел **Печать** (`/printers`) управляет CUPS через зарегистрированный HTTPS-helper. Локальные команды CUPS на сервере панели не выполняются. Установка пакетов доступна на главной странице: кнопка **＋** над серверами → **Сервер печати CUPS** → сервер → план → подтверждение. Установщик использует репозитории текущей ветки ALT и не меняет сетевые настройки ОС.

Консоль показывает службу и автозапуск, очереди, Linux-модели, Windows-пакеты, IPP/Kerberos и общий журнал. Очереди можно создавать, изменять, приостанавливать, возобновлять, назначать по умолчанию, запрещать/разрешать приём заданий и удалять. Перед изменениями показывается план с ревизией. Очередь с активными заданиями удалить нельзя: сначала завершите или отмените задания. Публикация в Samba включается отдельно от IPP.

Просмотр доступен пользователям с правом чтения. Изменения, установка, загрузка PPD/keytab и Windows-драйверов требуют администратора, CSRF и записываются в аудит. Секреты передаются только в теле запроса к helper; пароли в URI устройства запрещены.

## Драйверы Linux

Каталог строится из **всех моделей установленного CUPS** и импортированных PPD. Установка проверяет доступность Gutenprint, Foomatic и дополнительных драйверов в репозитории. Поиск, сортировка и страницы обрабатываются на сервере; список моделей не загружается целиком в браузер.

Можно загрузить PPD или архив ZIP/tar, включая вложенные архивы и DEB с PPD. Установщики производителя не запускаются, пути из архивов не извлекаются в файловую систему. Повторные PPD определяются по SHA-256. Формат проверяет `cupstestppd`. Ошибочные PPD сохраняются в каталоге с ошибкой проверки и недоступны для назначения. Модель с отсутствующим фильтром также недоступна до установки соответствующего доверенного пакета. Команды Foomatic и небезопасные пути фильтров из загруженных PPD отклоняются.

Источники:

- [OpenPrinting](https://www.openprinting.org/printers), Gutenprint/Foomatic из ALT — современные и старые модели.
- [Катюша](https://katusha-it.ru/downloads) — официальные пакеты. Проверенный архив Universal Driver 2.1-1 содержит 35 PPD, в том числе внутри DEB; часть содержит ошибки UIConstraints, отдельные фильтры рассчитаны на x86-64. Импорт не делает их автоматически совместимыми с aarch64. SHA-256 проверенного архива: `83457754520049c4c8138d493013e0d21068e4a9d2b5259977688fa1eecc514c`.
- [Sindoh](https://www.sindoh.com/en/business/printing-solution/download) — PPD/пакеты конкретных моделей. Их можно импортировать тем же способом.
- [LPrint](https://www.msweet.org/lprint/) — IPP-сервер для этикеточных и чековых принтеров; общего каталога PPD у него нет. Его очередь можно подключить по IPP Everywhere. Управление собственной службой LPrint в консоль не входит.

Проприетарные PPD и фильтры не включены в исходники sambaadm. Полная поддержка любой когда-либо выпущенной модели не гарантируется: важны язык принтера, фильтр, архитектура и лицензия производителя.

## IPP и два сценария keytab

**Вход пользователей.** Зарегистрируйте уникальный SPN `HTTP/print.example.org` на служебной записи AD. В разделе **IPP / Kerberos** загрузите её keytab, укажите HTTP principal, UPN владельца SPN и KDC. Helper проверяет ключ получением TGT владельца и расшифровкой HTTP service ticket исходным keytab. Ключ с ошибочным SPN не активируется. Затем проверьте и примените сетевую политику CUPS с Kerberos и автозапуском.

Используйте FQDN и доверенный сертификат IPPS. Сертификат CUPS нужно распространить на клиентов или заменить сертификатом доверенного УЦ средствами CUPS. Для Linux-клиента укажите `GSSServiceName HTTP` в `client.conf` либо переменную `CUPS_GSSSERVICENAME=HTTP`. По умолчанию некоторые сборки libcups используют другое имя GSS-службы.

**Исходящая печать по SMB.** Загрузите отдельный keytab служебной записи с правом печати на целевом сервере. Helper получает билет от пользователя CUPS (`lp`), запускает постоянную службу и таймер обновления каждые 30 минут, передаёт `KRB5_CONFIG`/`KRB5CCNAME` backend через `PassEnv`. После применения политики IPP создайте очередь `smb://server.example.org/queue` с подходящим установленным драйвером. Эта схема отправляет задания от служебной записи; имя исходного пользователя сохраняется в журнале исходного CUPS.

Keytab имеет режим 0600. HTTP и Windows keytab доступны root; SMB keytab — пользователю CUPS. Пароли и ключи не возвращаются в браузер и не помещаются в аргументы процессов.

## Windows

Загрузите ZIP с INF и распакованными файлами драйвера Type 3, выберите архитектуру, DLL драйвера, Data/Config/Help и зависимые файлы. При необходимости укажите существующую опубликованную очередь Samba. EXE-установщики не запускаются. Для регистрации нужен отдельный проверенный Windows keytab с правами администратора печати и сопоставлением Unix UID на сервере Samba.

Helper подготавливает `print$` в `/var/lib/samba/printers`, проверяет `smb.conf`, публикует файлы и регистрирует их через Kerberos RPC `adddriver`, затем при выборе очереди — `setdriver`. Файлы размещаются в каталоге архитектуры, а spoolss переносит зарегистрированные файлы в `3/`. Несовпадающие файлы с одинаковыми именами не перезаписываются. Существующий `print$` с другим путём автоматически не заменяется.

Point and Print и установка на Windows подчиняются доменным политикам и требованиям подписи драйвера. Серверная регистрация не подтверждает совместимость драйвера с конкретной версией Windows или физическим принтером.

## Общий журнал

Журнал собирается с helper-узлов каждые 30 секунд, даже без открытого браузера. Сохраняются время, узел, номер задания, очередь, пользователь, название, состояние, причины, страницы и листы. Есть поиск, фильтры сервера/очереди/пользователя/состояния/дат (UTC), сортировка и страницы. CUPS хранит до 10000 заданий на узел; панель — до 100000 наблюдавшихся заданий в `server.settings_dir/printing-journal.json` (0600, до 64 МиБ). Уже собранная история остаётся после удаления очереди. Недоступные узлы и ошибки архива показываются явно.

Документы не архивируются (`PreserveJobFiles No`). Это журнал наблюдавшихся заданий: недоступность панели дольше срока хранения CUPS может привести к пропускам.
