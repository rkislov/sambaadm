# v0.45.25 — DNS: выбор BIND и права helper

Включает [делегирование, условную пересылку и переключение DNS-бэкенда](https://github.com/rkislov/sambaadm/blob/v0.45.25/docs/dns-routing.md).

- Для общей доставки автоматически выбираются обнаруженные работающие BIND. Недоступные и неподдерживаемые узлы показаны отдельно; текущий DNS-бэкенд остальных DC не меняется.
- Исправлены разрешённые каталоги sandbox службы helper: конфигурация BIND на ALT размещается в `/var/lib/bind/etc` через символьную ссылку `/etc/bind`. Helper может создавать предпросмотр, резервную копию и применять конфигурацию без отключения `ProtectSystem=strict`.
- Проверка пакетов использует закрытый кэш helper и не требует прав записи в системный кэш APT.
- Перед применением проверяются все выбранные узлы; отчёт сохраняет результат каждого сервера.

Обновите панель и helper. Установка пакета не переключает DNS автоматически. Для пересылки поддомена своей AD-зоны сначала создайте делегирование.

Проверки: реальный временный домен с Samba/BIND, переключение бэкендов в обе стороны, пересылка к отдельному DNS под родительской AD-зоной, обработка ошибок и предпросмотр в браузере.
