# sambaadm v0.50.0 — единая панель управления доменом Samba AD

sambaadm объединяет ежедневное администрирование Samba Active Directory в русском веб-интерфейсе. CLI и REST API доступны для автоматизации, helper — для операций на контроллерах и других Linux-серверах.

## Что входит в выпуск

- **Учётные записи и работа с сотрудниками.** Пользователи, группы, компьютеры и OU; разблокировка и диагностика входа; PSO и результирующая парольная политика; мастера приёма, перевода и увольнения; массовые операции с предпросмотром и результатом по каждому объекту.
- **Групповые политики.** Редактор с конфигурациями компьютера и пользователя, ADMX/ADML, сценарии и сетевые диски; привязки, права, моделирование и RSoP; проверка и доставка SYSVOL между контроллерами.
- **DNS.** Зоны и записи, делегирование поддоменов, условная пересылка и доставка правил на выбранные BIND9 DLZ. На ALT Linux доступно переключение встроенного DNS Samba на BIND9 DLZ и обратно с проверкой SOA/SRV.
- **Контроллеры и обслуживание домена.** FSMO, сайты и подсети, карта топологии, репликация, RODC, аудит и диагностика; резервное копирование и поддерживаемые сценарии восстановления домена.
- **Развёртывание и доступ.** Пакеты и установочные комплекты для ALT x86_64 и ARM64, HTTPS с доменным именем, Kerberos SSO с сохранением входа по паролю, установка и регистрация helper из панели. В комплекте релиза есть плагин Caja для предыдущих версий файлов SMB.

## Надёжность доставки DNS

Доставка показывает результат каждого контроллера. При недоступности одного helper остальные выбранные BIND-серверы могут получить правило. Повторная попытка перечитывает настройки недоставленных узлов и пропускает уже совпадающие правила без повторной записи.

Если другой администратор изменил конфигурацию после предпросмотра, устаревшее применение отклоняется с HTTP 409. Повторная попытка показывает свежий предпросмотр, сохраняет остальные правила и требует нового подтверждения.

На стенде DC0/DC1/DC5 проверены переключение DNS-бэкенда в обе стороны с сохранением зон и записей, доставка пересылки на все BIND-контроллеры, реальные DNS-запросы, частичный сбой helper и конфликт двух сессий. Тестовые изменения после приёмки удалены.

## Установка и обновление

Обновите панель и helper до одной версии. Для существующей RPM-установки используйте штатное обновление пакетов; повторная первоначальная настройка домена не требуется. Перед обновлением сверяйте файлы с `SHA256SUMS`.
