# sambaadm 0.54.0 — управляемая синхронизация GPO с Windows DC

В разделе «Групповые политики» добавлена страница «Синхронизация SYSVOL». Администратор выбирает Windows или Samba RWDC источником, политики и Samba DC с helper получателями, проверяет предпросмотр и подтверждает перенос.

- Источник читается напрямую через SMB с Kerberos и обязательной подписью, без helper и без перехода на NTLM. На источник ничего не записывается.
- Проверяются LDAP-метаданные, GPT.INI, отдельные версии компьютерной и пользовательской частей, SHA-256, владельцы, группы и DACL. Понижение версий блокируется.
- Готовые пары GPO/DC доставляются независимо. Конфликты источника и получателя после предпросмотра не затираются; изменения получателя после прошлой доставки требуют разбора.
- Используется проверяемое переключение каталога GPO с защищёнными снимками и сохранением исходной копии. Неподтверждённая операция требует восстановления.
- Повторный предпросмотр, защита от повторного применения, журнал после перезапуска, выгрузка отчёта и аудит. Совпадающие копии повторно не записываются.

Переносятся деревья существующих GPO в Policies/{GUID}. Отдельный NETLOGON, центральное хранилище ADMX, SACL и дополнительные потоки не включены. Постоянная DFSR и расписание не настраиваются.

**Проверка с настоящим Windows DC ещё предстоит:** тестовый Windows Server пока отсутствует. Протокольные проверки используют изолированный Samba AD, в том числе источник без helper. Перед рабочей миграцией нужен пилот Windows AD, доверенные сертификаты LDAPS и проверка применения политик клиентами.
