# sambaadm v0.42.0

- «Сайты и службы Active Directory» используют компоновку RSAT. Слева дерево сайтов, серверов, подсетей и транспорта IP. Справа список и действия для выбранной ветви. Можно создать сайт или подсеть, переназначить подсеть, перенести контроллер и изменить свойства связи сайтов.
- В GPO появилась «Результирующая политика (RSoP)». Откройте XML, сохранённый на Windows командой `gpresult /x result.xml`. Отчёт показывает разделы компьютера и пользователя, состояние GPO, параметры, источник и приоритет из отчёта. Файл обрабатывается в браузере. Прямой сбор с компьютеров по сети в эту версию не входит.
