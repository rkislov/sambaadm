# sambaadm v0.41.0

- Диспетчер DNS в стиле RSAT: зоны прямого и обратного просмотра, дерево имён, таблица записей, поиск, фильтр типа, страницы и отдельные свойства записи с TTL. Точный запрос узла исключает записи дочерних имён.
- Каталог импортирует все ADMX/ADML из настроенного источника: Windows, ALT и других производителей, включая UTF-16. Политики ALT отмечены плашкой. Неподдерживаемые определения остаются только для чтения.
- Шаблоны постоянно хранятся локально и переживают перезапуск. Обновление — только по кнопке в настройках. Проверка исходных шаблонов перед сохранением политики не заменяет локальный каталог.
- Убрано дублирующее дерево списка GPO; дерево категорий редактора сохранено.
- Упрощено моделирование: пользователь и компьютер в основной форме, остальные условия в расширенных параметрах, краткий результат и раскрываемые технические подробности. Неизвестные условия остаются неизвестными, пока пользователь явно не задаст допущение.

Обновите sambaadm и sambaadm-helper до v0.41.0. Затем нажмите обновление каталога шаблонов в настройках, чтобы заменить прежний каталог только ALT полным набором. Шаблоны Windows не встроены и не скачиваются: разместите ADMX/ADML в настроенном gpo.admx_path либо Central Store SYSVOL. Поддержка редактирования ограничена распознаваемыми конструкциями; результат применения проверяется на клиенте.

Проверки: Go race tests и vet, браузерные сценарии редактора, моделирования и DNS; CI дополнительно проверяет DNS RPC на Samba и установку/обновление пакетов ALT.
