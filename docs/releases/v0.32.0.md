# v0.32.0 — helper и управление RODC

Отдельный `sambaadm-helper` выполняет операции ОС, файлов и SYSVOL на управляемых Linux-серверах, включая основной. Поддерживаются SSH и HTTPS API с подписью Ed25519; закрытый ключ остаётся на сервере управления. LDAP, DNS и DRS остаются в sambaadm. Копирование политик использует helpers источника и получателя.

## Новые возможности

- Выбор RODC и назначение пользователей, компьютеров и security groups в разрешающие и запрещающие списки Password Replication Policy конкретного контроллера.
- Предпросмотр и принудительное заполнение кэша отдельных пользователей/компьютеров с результатом по каждой записи. Источник — настроенный записываемый DC.
- Просмотр кэшированных записей, сведений каталога об авторизациях и локального JSON-аудита Authentication выбранного RODC через helper.
- Очистка архивов исправления SYSVOL по лимитам с предпросмотром, защищённым последним архивом каждого DC и продолжением после сбоя. Автоматического удаления по таймеру нет.
- Новые редакции инструкций администратора и пользователя в Markdown и Word.

## Переход с предыдущей версии

**Для операций ОС, файлов и SYSVOL теперь обязательна настройка helper.** Установите отдельный пакет на все затрагиваемые DC и файловый сервер, настройте ключи и SSH/HTTPS, затем заполните `helpers.nodes` и `helpers.host_node` в sambaadm. Без helpers доменные LDAP/DNS/DRS остаются доступны при наличии прав, а файловые операции завершаются ошибкой настройки. Прямой SMB из управляющего приложения больше не используется.

Сохраните конфигурацию, ключи и состояние `/var/lib/sambaadm`, завершите pending-операции GPO. Файловые backup/restore выполняются на helper host_node внутри `helper.backup_root`. Основной RPM и helper обновляются отдельно; пакетный инструмент `sambaadm-package` управляет только основным приложением. Снятие разрешения PRP не очищает уже закэшированные пароли.

Порядок установки: [руководство администратора](https://github.com/rkislov/sambaadm/blob/v0.32.0/docs/admin.md), [SSH/HTTPS и ключи](https://github.com/rkislov/sambaadm/blob/v0.32.0/docs/helper.md), [обновление ALT](https://github.com/rkislov/sambaadm/blob/v0.32.0/docs/alt-install.md). Для операторов: [руководство пользователя](https://github.com/rkislov/sambaadm/blob/v0.32.0/docs/user.md).

## Состав поставки и проверки

Бинарники sambaadm для Linux, macOS и Windows; helper для Linux; отдельные RPM sambaadm и sambaadm-helper для x86_64/aarch64; два Word-руководства; архив документации, конфигураций и deployment-файлов; SHA256SUMS.

Проверены Go-тесты с race detector, vet, браузерные сценарии, тестовый домен с двумя DC и RODC, оба транспорта, файловые ограничения и RPM lifecycle в ALT p10. Приёмка на реальном домене и ALT СП 10.2.2 остаётся отдельным шагом. Журнал авторизаций ограничен последними 8 МиБ и 500 подходящими событиями; отсутствие события не доказывает отсутствие входа.
