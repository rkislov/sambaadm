# v0.39.4 — понятные результаты репликации и чтение реальных GPO

- «Последний результат» теперь показывает описание с кодом в скобках:
  «Успешно (0)», «Узел недоступен по сети (1232)». Частые ошибки переведены;
  для остальных известных кодов используется описание Win32 из библиотеки
  протокола. Неизвестный код сохраняется. Числовое поле API не меняется,
  добавлено отдельное resultDescription.
- Ожидание запуска DRS-репликации увеличено до 5 минут. Настройка YAML
  gpo.replication_timeout принимает длительность от 1s до 30m, например 10m;
  переменная окружения — SAMBAADM_GPO_REPLICATION_TIMEOUT. Увеличиваются
  общий бюджет и сетевое ожидание именно SyncReplica; короткие запросы
  состояния и 15-секундное подключение к недоступному узлу сохраняются.
  Доставка всех GPO-шагов по-прежнему ограничена общими 30 минутами.
- Чтение версии GPT.INI допускает однобайтовые метаданные Windows без
  ошибочного требования UTF-8. При обновлении версии остальные байты
  сохраняются без угадывания кодовой страницы. Поддерживаются UTF-8 с/без BOM
  и UTF-16LE/BE с/без BOM. Некорректный Unicode/NUL и неправильные версии
  отклоняются. Ошибки согласованности указывают путь к политике и GPT.INI.
- Пробелы вокруг записей gPLink больше не ломают чтение. Повреждённый gPLink
  или gPOptions одного контейнера не закрывает форму моделирования всего
  домена: показываются DN и причина. Расчёт затронутой ветви и запись в
  повреждённый контейнер заблокированы; данные AD автоматически не исправляются.

- В формах резервного копирования/восстановления уточнено, что путь относится
  к узлу helper и должен быть абсолютным, внутри helper.backup_root. Добавлены
  пример и проверка формы: ~/backup/ не отправляется helper. Основной сервис
  также отклоняет относительный путь до чтения GPO. Тильда не раскрывается
  в домашний каталог root либо пользователя браузера.

Обновите основной sambaadm и перезапустите службу. Helper 0.39.0 и новее
совместим, его обновление для этих исправлений не требуется. Тайм-аут 5 минут
применяется по умолчанию без редактирования существующего config.yaml.
