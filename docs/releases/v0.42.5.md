# sambaadm v0.42.5

Исправлено отображение репликации контроллеров только для чтения (RODC). Панель запрашивает входящих соседей отдельно по каждому разделу и показывает время и результат последней попытки, а также время последней успешной репликации.

Если по разделу нет данных, панель показывает «Состояние не подтверждено» и сохраняет результаты по остальным разделам.
