# v0.37.2 — исправление прав журналов при установке и запуске

RPM и ручной установщик подготавливают audit.log и events.log в /var/log/sambaadm: владелец sambaadm:sambaadm, права 0640, каталог 0750. Существующее содержимое сохраняется. Это исправляет отказ запуска службы после ручного запуска приложения от root, создавшего журналы с правами root.

Перед каждым запуском systemd-службы выполняется та же подготовка с правами root; основной процесс продолжает работать от sambaadm. Символические ссылки, специальные файлы и файлы с несколькими жёсткими ссылками на месте штатных журналов отклоняются без изменения целевого файла. Пользовательские пути журналов за пределами штатных двух файлов не меняются.

Обновите RPM обычным способом через sambaadm-package update. Для ручной установки повторите deploy/install.sh из исходников этой версии. Обновление одного бинарника без установщика не обновляет systemd-unit и сценарий подготовки журналов. Конфигурация и пароли сохраняются. На удалённых helper отдельного исправления не требуется: их служба работает от root.
