# sambaadm v0.42.1

- Рабочие разделы получили общую компоновку. Дерево объектов и команды раздела находятся слева, список, поиск и создание объектов — справа. В настройках и сертификатах есть навигация по подразделам. Главное меню сохраняет плитки.
- Раздел называется «Сайты и службы». В дереве доступны сайты, серверы, подсети и связи IP.
- В GPO ветвь «Моделирование групповой политики» показывает имя сценария, пользователя, компьютер и дату последнего расчёта. Можно открыть результат, пересчитать сценарий или скачать отчёт JSON. Список сценариев доступен до перезагрузки страницы.
- Соседняя ветвь «Результаты групповой политики» открывает XML Windows `gpresult /x result.xml` в правой панели.
