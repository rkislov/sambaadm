# v0.45.28 — корректное чтение параметров Samba при смене DNS

- Диагностический stderr `testparm` отделён от stdout. Предпросмотр больше не включает предупреждения и служебные сообщения в `server services`.
- Чтение DNS-параметров и realm использует только stdout; диагностические сообщения сохраняются в журнале отдельно.
- Включены настройка свежего BIND для ALT, создание ключа rndc, обновление индексов пакетов и корректный статус продолжающегося отката.

Обновите панель и helper. [Инструкция](https://github.com/rkislov/sambaadm/blob/v0.45.28/docs/dns-routing.md) · [Плагин Caja](https://github.com/rkislov/sambaadm/blob/main/docs/caja-plugin.md).
