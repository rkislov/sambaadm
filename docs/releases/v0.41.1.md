# sambaadm v0.41.1

Исправлен импорт Windows ADMX/ADML с объявлением `encoding="unicode"`, в частности Search.admx. Загрузчик распознаёт этот псевдоним после определения и проверки UTF-16; поддерживаются оба порядка байтов с BOM и без него. Проверки повреждённых последовательностей и неизвестных кодировок сохранены.

Обновите sambaadm и sambaadm-helper до v0.41.1, затем повторите «Импортировать / обновить шаблоны» в настройках. Менять сами шаблоны не требуется.

Проверено чтение ADMX и русских ADML с объявлениями utf-16/unicode, включая разные регистры, BOM и оба порядка байтов; тесты отклонения повреждённых файлов, Go race tests и vet.
