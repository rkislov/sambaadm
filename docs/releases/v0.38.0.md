# v0.38.0 — Tailwind-интерфейс, сертификаты и обновление установки

В настройках появился раздел «Сертификаты и подключения»: проверка сертификата
LDAP-контроллера, выпуск и продление с DNS SAN через локальный УЦ, загрузка CA,
применение доверия без перезапуска и возврат к доверию из конфигурации. Выпуск
поддерживает CSR или создание нового ключа в скачиваемом ZIP. Установка файлов
на контроллер и перезапуск Samba остаются отдельным действием администратора.

Форма helper разбита на шаги с адаптивными полями, отдельными флажками и копированием
команд. Ключ и сертификат можно создать прямо в меню; для существующего ключа
доступна загрузка CSR. Приватный ключ нового helper не сохраняется на сервере.

CPU, RAM и системный диск сервера sambaadm измеряются локально без helper,
независимо от назначенного helpers.host_node.

Обновите RPM и откройте Настройки → Управлять сертификатами. Существующие YAML
сохраняются. Добавлен server.certificate_dir с умолчанием
/var/lib/sambaadm/certificates; включите его в закрытое резервное копирование.
Установка файлов на удалённых узлах автоматически не выполняется.

Подробности: docs/certificates.md и docs/helper.md в архиве документации.

Все формы и рабочие разделы используют общий дизайн на Tailwind CSS 3.4:
парящие плитки разделов с иконками, спокойные таблицы, единые поля и диалоги.
Представления вынесены в отдельную панель; операции доступны в меню «Действия».
CSS встроен в бинарник; CDN и Node.js на сервере не требуются.

setup-alt.sh принимает новую версию поверх установленной и повторный запуск
для той же версии. Перед заменой сохраняются конфигурации, ранее запущенные
изменяемые службы останавливаются и запускаются снова. Остановленные службы
остаются остановленными. Ключи, пароли, YAML и состояние сертификатов сохраняются.
sambaadm-package install распознаёт обновление; повтор той же версии безопасен.
Ручной установщик заменяет бинарник атомарно, включая работающую программу.
