# v0.45.30 — доставка DNS при частичном сбое

- Недоступность одного выбранного BIND-контроллера при предпросмотре больше не блокирует применение правила на доступных серверах.
- Отчёт показывает доставленные, уже актуальные и недоставленные узлы. Кнопка «Повторить для недоставленных» перечитывает настройки только неуспешных серверов и сохраняет их остальные правила.
- Совпадающие правила пропускаются без повторной записи. Повторная попытка после потери ответа не создаёт дублей.

Обновите панель sambaadm. Изменений протокола helper нет. [Инструкция DNS](https://github.com/rkislov/sambaadm/blob/v0.45.30/docs/dns-routing.md) · [Плагин Caja](https://github.com/rkislov/sambaadm/blob/main/docs/caja-plugin.md).
