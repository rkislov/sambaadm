# v0.39.1 — тестовый LDAPS без проверки сертификата

В расширенные параметры входа добавлена отдельная галочка «Не проверять
LDAP-сертификат (только для теста)». Она выключена по умолчанию и действует
только для текущей сессии. Помогает при `certificate signed by unknown authority`
и других ошибках сертификата; соединение остаётся зашифрованным, но подлинность
сервера не подтверждается и возможен перехват пароля. Для рабочего окружения
следует добавить доверенный CA и использовать проверку.

Соединения этого режима отделены от строгих и CN-совместимых сессий. Выбор
передаётся фоновым LDAP-операциям, отмечается в аудите и в верхней панели.
Автоматического обхода после ошибки нет. Проверка HTTPS-сертификатов helper
остаётся включённой. Обновите sambaadm и войдите заново; обновление helper
с версии 0.39.0 для этой галочки не требуется.
