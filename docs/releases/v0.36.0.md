# v0.36.0 — автонастройка сервера и автономное обследование домена

Для новой установки на ALT Linux скачайте комплект sambaadm-install для своей архитектуры и сверьте его с SHA256SUMS. В распакованном каталоге выполните `sudo sh setup-alt.sh all`. На отдельном управляемом узле используйте режим `helper`. Команда `sambaadm discover` определяет домен и контроллер по Samba и DNS. Перед сохранением мастер проверяет служебный вход по LDAPS и чтение Base DN.

Администратор может зарегистрировать HTTPS-helper в веб-интерфейсе и выпустить сертификат по CSR. Закрытый TLS-ключ остаётся на узле. Команда `sambaadm-helper collect` собирает локальный снимок для автономного обследования. Страница материалов принимает снимки, JSON обзора домена и журналы авторизаций. Из выбранных материалов можно сформировать сводный отчёт по площадкам.

Обновите приложение и helper одной версии по действующему порядку обновления. Автонастройка предназначена для новой установки. Имеющиеся статические подключения сохраняются. Для перехода на регистрацию узлов через веб используйте инструкцию helper.

На стенде ALT p10 aarch64 с systemd и отдельным контроллером Samba 4.17.12 проверены установка обоих RPM, обнаружение домена через DNS SRV, LDAPS, вход администратора, регистрация HTTPS-helper и получение метрик с контроллера. Приёмка на целевой ALT СП 10.2.2 остаётся отдельным этапом.
