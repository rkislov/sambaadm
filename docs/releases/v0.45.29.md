# v0.45.29 — проверенное переключение DNS-бэкенда на ALT

Включены исправления установки BIND, первого запуска rndc, чтения `testparm` и отката из v0.45.26–v0.45.28.

- Для локального неподписанного пространства AD задаётся точечное исключение DNSSEC `validate-except`. Проверка DNSSEC внешних доменов сохраняется; существующие локальные исключения не удаляются.
- Новая установка BIND наследует общие forwarders Samba и разрешает рекурсию локальным сетям и подсетям AD.

Обновите панель и helper. [Инструкция](https://github.com/rkislov/sambaadm/blob/v0.45.29/docs/dns-routing.md) · [Плагин Caja](https://github.com/rkislov/sambaadm/blob/main/docs/caja-plugin.md).
