# v0.35.0 — проверка восстановленного контроллера

Перед применением плана очистки sambaadm-helper запускает восстановленный DC в отдельной сети с доступом только через loopback. Временный обычный пользователь входит в LDAP и читает GPT.INI из SYSVOL по SMB отдельно с NTLM и Kerberos. Для Kerberos helper получает свежий TGT и билет CIFS. Ошибка запуска, входа или чтения блокирует очистку. Результат привязан к конкретному архиву и ревизии плана.

Обновите sambaadm и отдельный sambaadm-helper до 0.35.0. Для HTTPS перезапустите службу helper. После обновления получите новый план, создайте новую холодную копию и дождитесь подтверждения восстановления. Для допуска к очистке теперь нужны результаты обеих проверок. Предусмотрите место для восстановленного образа в частном /tmp службы.

Проверки восстановления выполнены на Samba 4.17/TDB. Приёмка на целевой ALT СП 10.2.2 остаётся отдельным этапом.
