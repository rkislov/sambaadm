# v0.40.0 — редактор политик в стиле RSAT и масштабируемая топология

## Редактор политик

Кнопка «Параметры ALT» переименована в «Редактор политик». Слева находится
дерево конфигураций компьютера и пользователя, административных шаблонов и
категорий; справа — таблица параметров с состоянием, шаблоном и путём.
Нажатие строки показывает описание, нажатие названия или двойной щелчок
открывает свойства. Состояние выбирается переключателями «Не настроено»,
«Включено», «Отключено».

Добавлены сортировка столбцов, фильтр состояния, поиск по каталогу и страницы
по 100 записей. Проверен каталог из 4500 параметров. «К списку параметров»
закрывает свойства без сохранения; запись по-прежнему требует подтверждения
и актуальной версии. Неподдерживаемые параметры и роли без прав изменения
остаются в режиме просмотра. Верхняя кнопка закрытия доступна при сохранении.

Это новый вид существующего редактора ADMX/Registry.pol. Набор поддерживаемых
расширений политик не расширяется до полного набора Windows RSAT.

## Топология репликации

Размер схемы и расположение узлов зависят от количества DC. Добавлены
увеличение и уменьшение, исходный масштаб, «Вписать целиком», перемещение
фона, поиск контроллера и фильтр по сайту. При более чем 20 DC по умолчанию
показываются связи выбранного узла; переключателем можно показать все линии.
Проверены наборы 0, 1, 8, 64, 256 и 1000 DC, а также мобильный экран.

Поиск, фильтрация, масштабирование и просмотр связей не изменяют AD.
Создание соединений по-прежнему доступно администратору после подтверждения.
Схема показывает конфигурацию, а не подтверждение исправности репликации.

## Обновление

Обновите основной sambaadm пакетом для архитектуры сервера и перезапустите службу:

```sh
rpm -Uvh sambaadm-0.40.0-alt1.x86_64.rpm
systemctl restart sambaadm
```

Для aarch64 используйте соответствующий RPM. Для этих изменений обновлять
helper не требуется; совместимые версии из ветки 0.39.x продолжают работать.
Обновление сохраняет существующую конфигурацию. После обновления перезагрузите
страницу браузера, чтобы загрузить новые скрипты и стили.

Проверки: Go-тесты и vet, браузерные сценарии редактирования, контроль доступа,
CSRF, конфликты версий, безопасный вывод текста шаблонов и мобильная раскладка.
