# v0.45.31 — проверка конфликтов доставки DNS

- Добавлена автоматическая регрессионная проверка: изменение правил после предпросмотра блокирует устаревшую запись; новый предпросмотр и применение сохраняют добавленное правило другого администратора без дублей.
- Дополнена инструкция по разрешению конфликта через «Повторить для недоставленных» и повторное подтверждение.

Приёмка на DC0/DC1 с BIND9 DLZ выполнена из двух независимых сессий: HTTP 409 на изменённом DC1, успешная доставка на DC0, повторная доставка только на DC1 с сохранением обоих правил. Тестовые настройки удалены, DNS и репликация исправны.
