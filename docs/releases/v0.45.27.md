# v0.45.27 — первый запуск и откат DNS-бэкенда ALT

Включает обновление индексов ALT и настройку новой установки BIND из v0.45.26.

- Перед проверкой конфигурации создаётся ключ управления rndc штатным init-скриптом ALT: пакетный шаблон ключа не мешает первому запуску.
- Повторная попытка после неудачной первой настройки распознаёт неизменённые пакетные настройки BIND и завершает подготовку для AD.
- Во время отката задание продолжает показываться работающим. Итоговый статус ошибки появляется после завершения восстановления; результат отката записывается отдельно.

Обновите панель и helper. [Инструкция](https://github.com/rkislov/sambaadm/blob/v0.45.27/docs/dns-routing.md) · [Плагин Caja](https://github.com/rkislov/sambaadm/blob/main/docs/caja-plugin.md).
