# v0.40.2 — постоянный локальный каталог шаблонов

Убран часовой срок действия импорта ADMX/ADML. Существующие каталоги также
становятся постоянными: возраст файла и перезапуск не вызывают повторного
импорта. Новые импорты не удаляют каталоги других источников или учётных записей.
Ограничение одного каталога 64 MiB и права 0700/0600 сохраняются.

Первое открытие по-прежнему импортирует шаблоны, если локального каталога ещё
нет. Дальнейшее обновление выполняется только кнопкой
«Настройки → Локальные шаблоны политик → Импортировать / обновить шаблоны».

Проверка источника перед сохранением GPO остаётся, но больше не обновляет
локальный каталог. Если шаблоны источника изменились, устаревшая версия
не позволит записать GPO: обновите шаблоны кнопкой, затем перечитайте параметры.
LDAP, GPT.INI и Registry.pol продолжают читаться с контроллера.

Достаточно обновить sambaadm и перезапустить службу. Helper 0.40.1 совместим;
для этого изменения его обновление не требуется. Для быстрой первичной загрузки
нужен helper 0.40.1 или новее. После обновления перезагрузите страницу браузера.
