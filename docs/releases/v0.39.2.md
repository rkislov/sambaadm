# v0.39.2 — доставка GPO на все контроллеры при частичных ошибках

Доставка политики больше не останавливается на первой ошибке контроллера.
После чтения исходной GPO выполняются все запланированные попытки DRS и
копирования SYSVOL на все остальные контроллеры. Ошибка DRS не отменяет
попытку копирования файлов на тот же контроллер; ошибка одного узла не
пропускает последующие узлы.

Задание остаётся в состоянии выполнения до завершения всех попыток, поэтому
интерфейс продолжает обновлять шаги и прогресс. Итоговый статус с ошибками
содержит сводку всех неудачных шагов, а успешные шаги сохраняют свой результат.
Если исходную политику/SYSVOL невозможно прочитать, доставка по-прежнему
останавливается: корректной копии для отправки в этом случае нет.

Обновите sambaadm и перезапустите службу. Обновление helper с версии 0.39.0
для этого исправления не требуется. Уже завершённые задания не перезапускаются
автоматически — доставку нужно запустить повторно.
