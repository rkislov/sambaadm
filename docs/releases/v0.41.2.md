# sambaadm v0.41.2

Импорт шаблонов продолжает работу после ошибки чтения или разбора отдельного ADMX/ADML. Исправные определения сохраняются, а пропущенные шаблоны отображаются в отдельном списке «Проблемные файлы» с именем и причиной. Диагностика передаётся через helper и сохраняется вместе с каталогом.

Если не удалось загрузить ни одного определения, прежний кэш остаётся без изменений. Недоступность всего источника, отмена, таймаут и общие ограничения размера по-прежнему завершают операцию ошибкой.

Обновите sambaadm и sambaadm-helper до v0.41.2, затем повторите «Импортировать / обновить шаблоны» в настройках.

Проверено: смешанный каталог с повреждёнными ADMX/ADML и нечитаемым файлом, обработка полностью ошибочного каталога, передача отчёта через helper, сохранение диагностики на диске, отмена запроса, браузерное отображение частичного результата и безопасный вывод текста ошибок, Go race tests и vet.
