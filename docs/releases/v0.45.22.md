# v0.45.22 — страницы журнала установки helper

- История установки и привязки helper разбита на страницы: 5, 10, 20 или 50 заданий. Старые задания больше не скрываются ограничением последних 20 записей.
- Длинный журнал каждого DC разделён на страницы по 25, 50 или 100 строк, есть переход к последним строкам.
- Автообновление сохраняет выбранные страницы, раскрытие журналов и положение чтения. Работающее задание продолжает отслеживаться, даже если находится на другой странице истории.
- Поздний ответ предыдущего запроса не возвращает интерфейс на старую страницу.
- Истёкшие планы отмечены в истории и не предлагают продолжение установки.

API `GET /api/v1/helper-install` принимает `page` и `pageSize` и возвращает
`jobs`, `page`, `pageSize`, `total`, `pages`, `running`, `packages`, `version`.
Выдаются только задания текущего администратора. Размер страницы — от 1 до 50,
по умолчанию 10. Отсутствующая страница при сокращении истории заменяется последней.

Обновление панели не требует повторной установки helper на контроллерах.
[Инструкция](https://github.com/rkislov/sambaadm/blob/v0.45.22/docs/helper.md#установка-на-выбранные-контроллеры-через-ssh).
