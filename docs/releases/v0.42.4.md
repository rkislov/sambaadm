# sambaadm v0.42.4

Отчёт о согласованности SYSVOL доступен в HTML и JSON. В сводке первыми показаны контроллеры, которые требуют внимания. В карточке контроллера указаны путь к папке GPO, ошибки чтения, расхождения и следующие шаги проверки. DN объекта LDAP указан в заголовке отчёта.

HTML можно открыть без подключения к sambaadm или распечатать. JSON включает манифест прочитанных файлов.
