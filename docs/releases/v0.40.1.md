# v0.40.1 — локальный каталог шаблонов и ускоренная загрузка редактора

Исправлена причина медленной загрузки редактора: чтение Central Store раньше
требовало множества обращений к helper с отдельными SMB-подключениями.
Новый helper получает поддерживаемый каталог через одно SMB-подключение.
Файлы самой GPO также читаются целиком вместо множества маленьких запросов.

Поддерживаемые определения ADMX/ADML импортируются в локальный кэш sambaadm
при первом открытии. В «Настройки → Локальные шаблоны политик» добавлена
кнопка импорта/обновления. Кэш текущей учётной записи хранится один час,
сохраняется после перезапуска и ограничен восемью каталогами по 64 MiB.
Каталог `server.settings_dir/admx-cache` имеет права 0700, файлы — 0600.
Пароли и данные GPO в кэш не записываются.

LDAP, GPT.INI и Registry.pol читаются с контроллера при каждом открытии.
Перед записью шаблоны перечитываются; устаревшие определения не обходят
проверку версии. Бинарный внутренний формат сохраняет значения перечислений,
булевы и другие записи реестра, отсутствующие в публичном JSON шаблона.

Добавлены ограничение загрузки двумя минутами, прошедшее время, понятный
результат таймаута и отмена чтения при закрытии окна. Ожидание блокировки
редактора также учитывает отмену запроса.

Для полного ускорения обновите **sambaadm и sambaadm-helper**:

```sh
rpm -Uvh sambaadm-0.40.1-alt1.x86_64.rpm
systemctl restart sambaadm
```

На каждом узле helper:

```sh
rpm -Uvh sambaadm-helper-0.40.1-alt1.x86_64.rpm
systemctl restart sambaadm-helper
```

Для aarch64 используйте соответствующие RPM. Старые helper совместимы, но
первая загрузка с них остаётся медленной. После обновления перезагрузите
страницу браузера и при необходимости нажмите импорт в настройках.
