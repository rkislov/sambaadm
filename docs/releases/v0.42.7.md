- Добавлена массовая доставка всех групповых политик домена из раздела GPO. Задание показывает ход репликации AD и копирования SYSVOL, включая ошибки на отдельных контроллерах.
- Helper проверяет чтение подготовленной копии SYSVOL по SMB от имени вошедшего пользователя до замены каталога политики.
- В обзоре домена показаны ошибки LDAP и SYSVOL по контроллерам. Неполная проверка отмечается и в экспорте JSON.

Для ALT Linux доступны пакеты SambaADM и helper для p10 и p11 на x86_64 и aarch64. Для проверки чтения при доставке обновите helper на целевых контроллерах.
