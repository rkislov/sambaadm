# v0.39.0 — учётные данные сессии и расширенные параметры входа

В окне входа появился блок «Расширенные параметры». Учётную запись вошедшего
пользователя можно использовать для SYSVOL на helper: пароль шифруется в памяти
sambaadm на время сессии, не записывается в конфиги/cookie и передаётся конкретному
helper по подписанному HTTPS/SSH-запросу. Выход, истечение сессии и перезапуск
приложения удаляют запись. Будущие запросы фоновых заданий не получают пароль
завершённой сессии и не переходят на служебную запись.

Режим LDAP legacy CN выключен по умолчанию и включается в расширенных параметрах
для конкретного входа. Допускается только сертификат без SAN с точным DNS CN.
Цепочка CA, сроки, назначение и имя остаются обязательными; чужой SAN, wildcard/IP CN
и ограниченные по именам цепочки без SAN отвергаются. Строгие и совместимые
LDAP-соединения не смешиваются между пользователями. Настройку по умолчанию
можно сохранить в меню сертификатов либо ldap.allow_legacy_cn.

Обновите sambaadm и sambaadm-helper на всех используемых узлах до 0.39.0 и
перезапустите службы. Повторно войдите в веб-интерфейс: пароль старой сессии не
сохранялся и восстановить его невозможно. Перевыпуск ключей и сертификатов не нужен.
Для передачи данных сессии требуется расширение протокола 2; старый helper
отклоняет такой запрос. Без режима сессии прежний протокол 1 продолжает работать.
LDAP/RPC-служебная запись приложения не заменяется учётной записью пользователя.

Подробности: session-credentials.md, certificates.md и helper.md в комплекте установки.
