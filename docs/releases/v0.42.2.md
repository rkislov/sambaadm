# sambaadm v0.42.2

Проверка согласованности GPO поддерживает до 100 обнаруженных контроллеров домена. Одновременно проверяются до четырёх DC. Бюджет чтения рассчитывается по размеру очереди и для 100 DC составляет 6 минут 15 секунд. На подготовку отводится до 45 секунд.

Закрытие окна проверки отменяет запрос. Отчёт JSON показывает лимит контроллеров и бюджет текущего запуска.
