# Быстрая установка sambaadm на ALT Linux

Для версии 0.51.0. Команды выполняются от root или через sudo. Скачайте RPM своей архитектуры (`uname -m`) и `SHA256SUMS` из одного [релиза](https://github.com/rkislov/sambaadm/releases/tag/v0.51.0), затем сверьте контрольную сумму пакета.

## Проверить источники и установить пакет

```sh
sudo apt-get update
apt-cache policy python3 openssl
```

Если обновление сообщает об ошибке источника или нужный пакет не имеет кандидата, **не выполняйте установку**. Сначала настройте доступные репозитории своей ветки ALT в `/etc/apt/sources.list` и `/etc/apt/sources.list.d/`, сеть и DNS; затем повторите проверку. Для ARM64 используйте RPM `sambaadm-0.51.0-alt1.aarch64.rpm`.

После успешной проверки установите пакет:

```sh
sudo apt-get install ./sambaadm-0.51.0-alt1.x86_64.rpm
```

## Создать новый лес

На чистом сервере с постоянным IPv4 и подготовленными временем и DNS выполните:

```sh
sudo samba-domain-init
```

1. Откройте HTTPS-адрес из консоли, сверьте отпечаток сертификата и введите временный код. По умолчанию мастер доступен на всех IPv4-адресах, TCP/8445.
2. Задайте домен, NetBIOS, имя и IPv4 DC, сайт, DNS-пересыльщик, уровень леса и HTTPS-имя панели. Проверьте сервер и пакеты, затем задайте пароль Administrator и подтвердите развёртывание.
3. После завершения настройте доменный DNS и доверие к публичному УЦ на административной машине. Откройте HTTPS-имя панели и войдите как `Administrator@ВАШ-ДОМЕН`. Helper первого DC устанавливается и привязывается автоматически.

Для дополнительного RWDC/RODC используйте работающую панель: **Сайты и службы → Развернуть контроллер**. Создайте A-запись нового сервера, если имя ещё не разрешается, подключите helper по SSH, затем выберите роль и сайт. [Полная инструкция со скриншотами](domain-init.md).

## Подключить панель к существующему домену

1. В DNS создайте A-запись `sambaadm.ВАШ-ДОМЕН` на IP сервера панели.
2. Выполните `sudo sambaadm-setup`. Укажите существующие домен, DC, служебную запись `login@domain`, её пароль, публичный PEM-сертификат ЦС LDAPS и HTTPS-имя панели.
3. Мастер проверит LDAP, выпустит HTTPS-сертификат с DNS SAN на 10 лет и запустит службу. Откройте `https://sambaadm.ВАШ-ДОМЕН/login`, настройте доверие к публичному УЦ и войдите доменной учётной записью.

Закрытый ключ УЦ распространять нельзя. Команда `sambaadm-setup` не создаёт новый лес и не присоединяет DC.

## Прослушивание HTTPS и HTTP

По умолчанию HTTPS слушает **`0.0.0.0:443` — все IPv4-адреса сервера**. Разрешите этот порт из административной сети. Проверка:

```sh
systemctl is-active sambaadm
sudo ss -ltnp 'sport = :443'
```

Для HTTP используйте `sudo sambaadm-setup --http`: адрес по умолчанию — **`0.0.0.0:8080`**, все IPv4-интерфейсы. Открывайте `http://IP-СЕРВЕРА:8080/login`. Если HTTP-панель уже настроена на `127.0.0.1:8080`, замените существующий параметр `server.listen` в `/etc/sambaadm/config.yaml` на `0.0.0.0:8080` и выполните `sudo systemctl restart sambaadm`.

`SAMBAADM_SERVER_LISTEN` из `/etc/sambaadm/env` имеет приоритет над YAML. `0.0.0.0` — адрес прослушивания, в браузере используйте настоящее DNS-имя или IP сервера. Диагностика запуска: `sudo journalctl -u sambaadm -n 50 --no-pager`.

## SSO сертификаты и обновление

Kerberos SSO подключается дополнительно: передайте `sambaadm-setup` отдельный keytab для `HTTP/sambaadm.ВАШ-ДОМЕН` через `--sso-keytab /etc/sambaadm/http.keytab`. Нужны доменный билет пользователя, доверие к HTTPS и разрешение Negotiate в браузере. **Вход по логину и паролю остаётся доступен.** [Подготовка keytab и браузеров](alt-install.md#kerberos-sso-и-https).

Продление сертификата панели: `sudo sambaadm-renew-certificates`. Скрипт сохраняет имя и настройки входа, проверяет конфигурацию и перезапускает работающую службу; сертификаты внешнего ЦС продлеваются в этом ЦС. Выпуск и распространение сертификатов LDAPS существующих DC выполняются отдельно из раздела сертификатов панели.

Обновление настроенного сервера: `sudo sambaadm-package update /путь/новый.rpm`. Обновляйте панель и helper совместно. Повторный первоначальный запуск и развёртывание леса для обновления не нужны. [Полная установка, обновление и откат](alt-install.md) · [Подключение helper](helper.md).
