# Быстрая установка sambaadm на ALT Linux

Нужен RPM для вашей архитектуры (`uname -m`) с командой `sambaadm-setup`.
В старом релизе v0.45.0 этой команды ещё нет; она включена в новые сборки
из main. Используйте пакет и инструкции одной сборки.
Сверьте SHA-256 скачанного файла с `SHA256SUMS` этой сборки.

Подготовьте DNS-имя домена и DC, существующую служебную запись с правами
на нужные операции и публичный PEM-сертификат доверенного ЦС LDAPS.
Команды ниже выполняйте через `sudo` или от root без `sudo`.

1. Установите скачанный пакет. Замените имя файла на своё:

   ```sh
   sudo apt-get update
   sudo apt-get install ./sambaadm-ВЕРСИЯ-alt1.x86_64.rpm
   ```

2. Запустите мастер:

   ```sh
   sudo sambaadm-setup
   ```

   Проверьте домен, DC и группу администраторов; укажите существующую запись
   `login@domain` и файл ЦС. Пароль вводится скрыто. Мастер проверит LDAP,
   сохранит настройки, запустит службу и включит автозапуск.

3. Проверьте службу:

   ```sh
   systemctl is-active sambaadm
   ```

   Ожидаемый ответ: `active`.

4. На компьютере с браузером откройте туннель к серверу sambaadm:

   ```sh
   ssh -N -L 127.0.0.1:8080:127.0.0.1:8080 linux-user@server.example
   ```

   Оставьте терминал открытым. Перейдите в браузере на
   <http://127.0.0.1:8080/login> и войдите доменной записью `login@domain`.
   Если браузер работает на самом сервере, туннель не нужен.

При ошибке запуска: `sudo journalctl -u sambaadm -n 50 --no-pager`.
Настроенный сервер обновляйте без повторного запуска мастера.

Для LDAP, DNS и FSMO достаточно одного управляющего приложения.
Для удалённых операций с ОС и файлами установите и зарегистрируйте
`sambaadm-helper` на нужных узлах — установка RPM сама регистрацию не выполняет.
