# Быстрая установка sambaadm на ALT Linux

Нужен RPM вашей архитектуры (`uname -m`) версии 0.45.5 или новее.
Сверьте файл с `SHA256SUMS` этой сборки. Команды выполняются от root или через sudo.

1. Установите пакет:

   ```sh
   sudo apt-get update
   sudo apt-get install ./sambaadm-ВЕРСИЯ-alt1.x86_64.rpm
   ```

2. В DNS домена создайте запись `sambaadm.ВАШ-ДОМЕН`, указывающую на IP сервера панели.
   Запустите первоначальную настройку:

   ```sh
   sudo sambaadm-setup
   ```

   Укажите домен, DC, существующую служебную запись `login@domain`, её пароль,
   публичный PEM-сертификат ЦС LDAPS и имя HTTPS, например `sambaadm.ipr.loc`.
   Мастер проверит LDAP, выпустит сертификат HTTPS с DNS-именем в SAN на 10 лет,
   запустит службу и включит автозапуск.

3. Проверьте службу и откройте `https://sambaadm.ВАШ-ДОМЕН/login`:

   ```sh
   systemctl is-active sambaadm
   sudo ss -ltnp 'sport = :443'
   ```

   HTTPS слушает `0.0.0.0:443` — один порт на всех IPv4-интерфейсах.
   Разрешите TCP/443 из административной сети, если включён межсетевой экран.
   Импортируйте **публичный** корневой сертификат ЦС панели в доверенные ЦС
   компьютеров с браузером; путь мастер выведет при установке. Войдите доменной
   записью `login@domain`. Ключ ЦС распространять нельзя.

4. Для продления сертификата:

   ```sh
   sudo sambaadm-renew-certificates
   ```

   Скрипт сохраняет DNS-имя и настройки входа, проверяет конфигурацию,
   перезапускает работающую службу и возвращает прежнюю конфигурацию при ошибке.
   Сертификаты, выданные внешним ЦС, продлеваются в этом ЦС.

Kerberos SSO подключается дополнительно: передайте мастеру отдельный keytab
для `HTTP/sambaadm.ВАШ-ДОМЕН` через `--sso-keytab /etc/sambaadm/http.keytab`.
Нужны доменный билет пользователя, доверие к HTTPS и разрешение Negotiate
для имени панели в браузере. **Вход по логину и паролю остаётся доступен.**
[Подготовка keytab и браузеров](alt-install.md#kerberos-sso-и-https).

Если нужно изменить адрес прослушивания, отредактируйте существующий
`server.listen` в `/etc/sambaadm/config.yaml`, затем перезапустите службу.
`0.0.0.0:443` — все IPv4-интерфейсы, `[::]:443` — IPv6 (IPv4 зависит от ОС).
Проверьте `/etc/sambaadm/env`: `SAMBAADM_SERVER_LISTEN` имеет приоритет над YAML.
Для SSO сохраняйте HTTPS и доменное имя. Диагностика запуска:
`sudo journalctl -u sambaadm -n 50 --no-pager`.

Обновление настроенного сервера: `sudo sambaadm-package update /путь/новый.rpm`.
Повторно запускать первоначальный мастер не требуется. Для удалённых операций
с ОС и файлами зарегистрируйте helper на нужных DC. Сертификаты LDAPS всех DC
выпускаются и распространяются отдельно из раздела сертификатов панели.
