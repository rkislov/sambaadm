# Файловые кластеры в Samba Admin

Откройте **Файловые ресурсы → Файловые кластеры** под учётной записью
администратора. Панель находит кластеры по зарегистрированным хелперам.
Для просмотра уже работающего кластера повторное развёртывание не требуется.

## Мастер

1. Выберите два хелпера одной ветки ALT и задайте виртуальный IPv4 и имя SMB.
   Хелперы проверят репозитории и готовность ZFS. Если оба узла выделены
   под кластер и на них нет пулов, мастер может подготовить hostid и отключить
   штатный автоимпорт. [Узлы и адрес](01-nodes.png)
2. Укажите iSCSI-порталы, выберите обнаруженную цель и общий LUN. Хелперы
   соберут карту multipath и проверят два или более пути к выбранному WWID.
   [Хранилище](02-iscsi.png)
3. Укажите параметры Redfish. Проверка выключает и включает каждый узел
   по очереди и сверяет его boot ID после возврата.
   [Fencing](03-fencing.png)
4. Проверьте VIP, хелперы и WWID, укажите доменные параметры и подтвердите
   создание ZFS. Из списка кластеров можно вернуться к черновику и открыть
   журнал. [Развёртывание](04-deploy.png)

Скриншоты мастера сделаны с тестовой парой подписанных хелперов. В настройке
используется Redfish. Общий SMB-адрес должен иметь запись A в доменном DNS
с адресом VIP. [Параметры развёртывания](../filecluster-zfs.md)

## Состояние и снимки

На вкладке **Состояние** видны кворум, текущий владелец SMB и каждый путь
multipath. Подробности карты и WWID раскрываются на карточке узла.
[Работающий кластер p11](05-status.png) · [Отключён один путь](05b-path-loss.png) ·
[Мобильный вид](07-mobile.png)

На вкладке **Снимки** можно создать именной снимок вручную или открыть
**Автоснимки** и задать интервал и количество экземпляров. Таймеры работают
на обоих хелперах, а делать снимки может только текущий владелец SMB с кворумом.
Расписание и отметки о срабатываниях хранятся на общем ZFS dataset.
Первый автоснимок создаётся при ближайшем запуске таймера после включения,
последующие интервалы отсчитываются по UTC. Лимит затрагивает только
автоснимки, созданные расписанием этого кластера.

В меню **Действия** у снимка можно посмотреть сведения и скопировать путь
к предыдущей версии по SMB. Эти действия и состояние кластера доступны
администратору, Helpdesk и наблюдателю. Мастер, создание снимков, расписание
и восстановление доступны администратору.
[Меню наблюдателя на p11](../dashboard-ui/p11/file-cluster-readonly.png). [Список снимков](06-snapshots.png) · [Расписание](08-autosnapshots.png) ·
[Меню снимка](09-snapshot-menu.png)

## Проверка браузером

На живых p10/p11 проверены обнаружение работающего кластера, кворум, оба
пути multipath, реакция на отключение и возврат пути на резервном узле,
ручной снимок и срабатывание системного таймера. В тестах расписание
включалось на время проверки. На обеих ветках плановый перенос SMB на другой
узел сохранил расписание и не создал дубль за тот же интервал.

`testdata/web/file-cluster.cjs` проходит мастер через настоящий HTTP-роутер
и тестовые подписанные хелперы. Для отдельного прогона на одноразовом стенде
задайте `SAMBAADM_CLUSTER_BROWSER_LAB` с каталогом стенда и
`SAMBAADM_CLUSTER_SCREENSHOTS` с папкой вывода. Переменные
`SAMBAADM_CLUSTER_BROWSER_SNAPSHOT=1` и `SAMBAADM_CLUSTER_BROWSER_SCHEDULE=1`
добавляют тест ручного снимка и расписания соответственно.

## Восстановление файла или папки

Откройте **Снимки**, выберите меню нужного снимка и нажмите **Восстановить
из снимка**. Выберите файл или папку в дереве. По умолчанию панель пропускает
уже существующие файлы и сохраняет права существующих папок. Опция перезаписи
возвращает версии файлов и права папок из снимка. В предпросмотре виден
каждый путь и действие над ним. Файлы без соответствия в снимке остаются
на месте. При изменениях после предпросмотра хелпер запросит новый план.
[Предпросмотр восстановления](10-restore-preview.png)

На живых ALT p10 и p11 проверены восстановление отдельного файла и
объединение папки с удалённым вложенным файлом. Совпали числовые владельцы,
группы, режимы, расширенный атрибут, ACL файлов и наследуемые ACL каталогов.
Доменный пользователь с правами прочитал возвращённую версию по SMB,
пользователь без прав получил отказ. [Проверка p10](../filecluster-tests/restore-p10.log) ·
[Проверка p11](../filecluster-tests/restore-p11.log)
